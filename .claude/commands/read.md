## 문서 로딩 순서

아래 파일들을 순서대로 읽어라:

1. `AGENTS.md` (에이전트 헌법 — 역할 정의, 문서 우선순위, 행동 원칙)
2. `CLAUDE.md` (트리거 키워드, 빌드/배포/테스트 명령 규칙)
3. `ARCHITECTURE.md` (시스템 아키텍처 개요)
4. `docs/references/active-lessons.md` (최근 30일 활성 경고)
5. `docs/references/lessons.md` (최근 교훈 — 마지막 5개)

## 숙지 후 확인 사항

파일을 모두 읽은 후 아래 사항을 간략히 파악한다:

1. **현재 역할**: 사용자 요청에 따라 적합한 역할 식별
2. **활성 계획**: `docs/exec-plans/active/`에 진행 중인 계획 유무
3. **최근 교훈**: 현재 작업에 관련된 교훈 유무
4. **git 상태**: !`git status --short`
