# skill-evolution.md — 스킬/명령 변경 이력

> `.claude/commands/` 의 슬래시 명령이 생성·변경·삭제될 때마다 1행 기록.
> 스킬 리팩터링·디프 추적용. 반영자 또는 스킬 추가자가 작성.

---

| 명령 | 생성일 | 버전 | 설명 | 변경 이유 |
|------|--------|------|------|----------|
| /auto | YYYY-MM-DD | v1 | 완전 자율 개발 루프 | 초기 도입 |
| /plan | YYYY-MM-DD | v1 | 실행 계획 작성 | 초기 도입 |
| /implement | YYYY-MM-DD | v1 | 구현 | 초기 도입 |
| /review | YYYY-MM-DD | v1 | 품질 검토 | 초기 도입 |
| /test | YYYY-MM-DD | v1 | 로컬 테스트 | 초기 도입 |
| /tcp | YYYY-MM-DD | v1 | 빌드→테스트→커밋→푸시→배포 | 초기 도입 |
| /reflect | YYYY-MM-DD | v1 | 교훈 추출 | 초기 도입 |
| /main-apply | YYYY-MM-DD | v1 | 프로덕션 반영 | 초기 도입 |
| /read | YYYY-MM-DD | v1 | 컨텍스트 로딩 | 초기 도입 |
