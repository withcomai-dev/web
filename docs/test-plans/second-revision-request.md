## 실행 체크리스트 (필수)

> 각 항목은 **직접 실행**(click·type·fill_form·select_option 중 하나 이상)하고 `✅/❌/N/A` 판정.

### WP6 — 홈 카드 2×2
- [ ] 홈 하단 서비스 카드가 4개(공식 쇼핑몰·공식 네이버 블로그·원격 지원 서비스·유튜브 자료실)이고 데스크톱에서 2×2로 배치된다
- [ ] 네이버 블로그 카드를 클릭하면 blog.naver.com/withcom_ai 가 새 탭으로 열린다

### WP1 — 헤더 검색
- [ ] 헤더 검색 아이콘을 클릭하면 검색 오버레이가 열리고 입력란에 포커스된다
- [ ] 검색어(예: "AI")를 입력하면 유형 그룹(콘텐츠/공지/지원사업/AI TOOL)별 결과가 표시된다
- [ ] 결과 항목을 클릭하면 해당 상세 페이지로 이동하고 오버레이가 닫힌다
- [ ] 결과가 없는 검색어 입력 시 "검색 결과가 없습니다"가 표시된다
- [ ] ESC로 오버레이가 닫힌다

### WP2 — AI TOOL 게시판
- [ ] /smartwork-ai 의 AI TOOL 소개 카드 6개에 "자세히 보기"가 보이고, 카드 클릭 시 /ai-tools?cat={슬러그} 로 이동한다
- [ ] /ai-tools 카테고리 탭 6개를 각각 클릭하면 URL ?cat= 이 동기화되고 리스트가 전환된다
- [ ] 글이 없는 카테고리에서 빈 상태 안내가 표시된다
- [ ] (어드민) /admin/ai-tools 에서 새 글 작성(카테고리 선택·제목 입력·본문 입력·상태 게시) 후 저장하면 목록에 나타난다
- [ ] (공개) 방금 작성한 글이 /ai-tools 해당 카테고리에 노출되고, 클릭 시 상세(/ai-tools/view?slug=)가 열리며 "목록으로" 복귀가 동작한다

### WP3 — 업무활용 콘텐츠 고정 노출
- [ ] (어드민) /admin/contents 에서 글 1개를 "항상 노출(고정)" 체크 후 저장하면 목록에 고정 뱃지가 보인다
- [ ] 홈 CONTENTS 섹션에서 고정 글이 최신글보다 먼저, 고정 뱃지와 함께 노출된다 (최대 6개)

### WP4 — 문의하기
- [ ] /contact 좌측 패널에 이메일(withcomai@gmail.com)만 보이고 전화·주소가 없다
- [ ] 회사명 입력란 placeholder가 "WITHCOM AI"다
- [ ] (마이그레이션 후) /contact 하단에 문의 내역 리스트(유형·마스킹 이름·날짜·상태)가 표시된다
- [ ] (로그인) 문의 폼 제출 시 전송 완료가 표시되고 하단 리스트에 새 행이 나타난다

### WP5 — WITHCOM AI 표기
- [ ] 브라우저 탭 타이틀이 "WITHCOM AI | …"로 표시된다
- [ ] 푸터에 주소·전화가 없고 "이메일 withcomai@gmail.com"·"© 1999 WITHCOM AI"가 표시된다
- [ ] 홈·공지·문의 페이지 본문에 "위드컴정보" 표기가 없다

### 어드민 연쇄
- [ ] /admin/pages 콘택트 섹션 에디터에 전화·주소 입력란이 없고 "문의 내역 리스트 표시" 체크박스가 있다
- [ ] 어드민 사이드바에 "AI TOOL 소개" 메뉴가 보이고 클릭 시 /admin/ai-tools 로 이동한다
