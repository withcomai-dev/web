# 테스트 플랜 — 관리자 방문 대시보드 + 콘텐츠 조회수

> 대상: web.app (라이브). 자체 집계라 **배포 시점부터** 데이터 축적. localhost는 집계 제외.

## 사전 조건
- 앱 배포(수동 롤아웃 SUCCEEDED) + Firestore 룰(siteVisits) 배포 완료
- 관리자 계정으로 `/admin` 로그인 가능

## 시나리오

### A. 방문(페이지뷰) 집계
1. web.app 공개 페이지 여러 개 방문(홈 → 소개 → 콘텐츠 → AI TOOL 등)
2. `/api/track` beacon 전송 확인(DevTools Network, sendBeacon → 204)
3. `/admin` 대시보드 "홈페이지 방문" 섹션:
   - [ ] 오늘 방문(PV) ≥ 1
   - [ ] 오늘 순방문 ≥ 1 (동일 브라우저 재방문 시 순방문 증가 안 함)
   - [ ] 30일 추이 라인차트에 오늘 포인트 표시
   - [ ] "인기 페이지" 목록에 방문 경로 표시(한글 라벨 + 경로)

### B. 콘텐츠 조회수
1. 공개 콘텐츠 상세(`/contents/view?slug=…`) 열람
2. [ ] 해당 콘텐츠 `viewCount` 증가(같은 세션 재열람은 미증가)
3. AI TOOL / 지원사업 상세도 열람 → viewCount 증가 확인
4. `/admin` 대시보드 "인기 콘텐츠 TOP5"에 조회수 순 표시
5. `/admin/contents` 목록에 "조회수" 컬럼 표시

### C. 회귀
- [ ] 대시보드 기존 위젯(카드·최근30일 활동·문의 유형별) 정상
- [ ] 어드민 콘텐츠 저장 시 조회수 유지(덮어쓰기 안 됨)
- [ ] 봇 UA 방문은 집계 제외
- [ ] 비관리자/비로그인은 siteVisits 읽기 불가(룰), 방문 집계는 정상
