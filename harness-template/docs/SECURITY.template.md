## 절대 금지 사항

| 금지 항목 | 이유 | 위반 시 조치 |
|----------|------|------------|
| 시크릿/API Key 평문 저장 (DB/코드/로그) | 자격증명 탈취 위험 | 즉시 중단, 사용자 보고 |
| 복호화된 시크릿 콘솔/로그 출력 | 로그 유출 위험 | 즉시 중단, 사용자 보고 |
| 환경변수 클라이언트 노출 | 브라우저 공개 위험 | 즉시 중단, 사용자 보고 |
| 외부 서비스 ToS 위반 (스크래핑·스팸 자동화 등) | 계정 정지 위험 | 구현 거부 |
| 느슨한 타입(`any` 등) 사용 | 런타임 보안 취약점 경로 | 빌드 실패 (린트) |
| 스키마 검증 없는 외부 입력 처리 | 인젝션 위험 | 코드 리뷰 차단 |

## 암호화 규칙

### 사용자 시크릿 저장

- 알고리즘: **AES-256-GCM** (또는 프로젝트 표준)
- 구현: `{{ENCRYPTION_SERVICE_PATH}}`
- 복호화: **서버사이드 전용** — 클라이언트에 복호화된 값 절대 전달 금지

```
// ✅ 올바른 패턴
const encrypted = await encryptionService.encrypt(secret)
await db.insert(table).values({ encrypted_value: encrypted })

// ❌ 평문 저장 금지
await db.insert(table).values({ secret: rawSecret })
```

## OAuth / 토큰 관리

- 토큰 만료 전 자동 갱신 서비스 구현
- 토큰은 암호화 저장, 서버사이드에서만 복호화
- 외부 자동화는 사용자 동의(ToS) 후에만 활성화

// ✅ 안전한 에러 응답

## 자동화 안전장치 (해당 시 필수)

새 자동화 기능 구현 시 반드시 포함:
1. **긴급 정지** 연동
2. **사용자 동의(ToS)** 후에만 활성화
3. **실행 로그** 기록 — 모든 자동화 액션 추적
4. **중복 실행 방지** (분산 락)
5. **일일 한도 체크** — 플랫폼 한도 준수
