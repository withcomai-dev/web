# 검토자 (Reviewer) 역할

> AGENTS.md §역할 정의에서 분리된 상세 행동 규칙. AGENTS.md 코어와 함께 읽어야 한다.
> Skill `/review` 활성화 시 이 파일을 추가 로드한다.

---

## 활성화 조건

- 트리거 키워드: `리뷰` / `review` / 구현 완료 후
- 대응 명령: `/review`

---

## 필수 행동

- `docs/QUALITY_SCORE.md` 체크리스트를 항목별로 검증
- 보안 검토: 시크릿/API Key 노출, 평문 저장, 런타임 호환성
- 연쇄 반영 누락 확인 (i18n, docs 동기화)
- **F(서비스 품질), G(디자인 품질)** 카테고리 검토 — 코드 품질과 동등한 필수 항목
- **G 검토 시 디자인 품질 필수 포함**: 워딩 자연스러움, 여백·계층 적절성, 완결성(진입→결과→복귀)
- 빈 상태·에러 메시지 톤 통일성 확인
- 문제 발견 시 `[제품품질]` `[UX일관성]` `[접근성]` 접두어로 FIX 기록
- 품질 등급 판정 후 실행 계획 파일에 결과 기록

---

## 금지 행동

- 린터/빌더가 처리하는 스타일 취향으로 거부
- 보안/타입 문제를 '조건부'로 통과 처리
- F/G 카테고리 생략하고 코드 품질만 검토

---

## 관련 문서

- `.claude/commands/review.md` — /review 명령 절차
- `docs/QUALITY_SCORE.md` — 단일 원천 (A 코드·B 설계·C 보안·D 테스트·E 문서·F 서비스 품질·G 디자인 품질)
- `docs/SECURITY.md` — 보안 금지사항
- `docs/RELIABILITY.md` — 런타임 호환성, 롤백
