# docs/references — 학습 자료 & 교훈 아카이브

이 디렉토리는 **에이전트가 반복 실수를 피하도록** 과거 교훈·경고·스킬 변경 이력을 보관합니다.
3개 파일의 역할이 겹치지 않도록 **수명·쓰기 주체·소비 시점**을 엄격히 분리합니다.

## 파일 역할

| 파일 | 수명 | 역할 | 쓰기 주체 | 소비 시점 |
|------|------|------|----------|----------|
| `active-lessons.md` | 30일 (만료 제거) | 최근 경고 리스트 | 실수 발생 즉시, 모든 에이전트 | **모든 에이전트 작업 전 필수 로드** |
| `lessons.md` | 영구 | 상세 교훈 아카이브 | 반영자(`/reflect`) | 기획자(`/plan`) 참조 + 주간 정리 |
| `skill-evolution.md` | 영구 | 프로젝트 전용 스킬의 생성·변경 이력 | 반영자 / 스킬 추가자 | 스킬 리팩터링·디프 추적 시 |

## 승격·소멸 규칙

### active-lessons.md → lessons.md (상세 교훈으로 기록)
- **자동 대상 (즉시 승격)**: 보안/안정성 이슈는 1회 발생도 바로 `lessons.md`에 정식 기록
- **일반 대상**: 30일 내 동일 유형 **2회 이상** 재발 → `lessons.md`로 승격
- 승격되지 못한 일반 교훈은 만료 시 삭제

### lessons.md → 영구 규칙 승격
- 동일 카테고리 교훈이 **5건 이상 누적** → 해당 가이드 문서(`AGENTS.md`, `CLAUDE.md`, `RELIABILITY.md`, `SECURITY.md` 중 하나)에 규칙으로 편입
- 승격 후 원본 항목에 "→ 승격 완료: {문서명} #{섹션}" 주석 추가

## 쓰기 형식

### active-lessons.md 항목
```
## {YYYY-MM-DD} | {에이전트명} | {패턴 한줄 요약}
- **패턴**: {어떤 상황에서 발생하는가}
- **차단 방법**: {다음에 어떻게 피하는가}
- **만료**: {30일 후 날짜}
```

### lessons.md 항목
```
### {YYYY-MM-DD} | {카테고리} | {한줄 요약}
- **상황**: {무엇이 일어났는가}
- **원인**: {왜 일어났는가}
- **해결**: {어떻게 해결했는가}
- **교훈**: {다음에 어떻게 예방하는가}
- **적용**: {어떤 문서/규칙에 반영했는가}
```
